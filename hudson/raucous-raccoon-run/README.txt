RAUCOUS RACCOON RUN
===================
Host this folder on any static web server. Upload index.html, style.css and game.js together in the same directory. No external libraries, fonts, or audio files are needed.

Or open index.html directly in a desktop browser.

CONTROLS
Left/right arrow keys or A/D to switch lanes; on mobile, use on-screen buttons or swipe. Escape to pause.

GAME RULES
Collect pizza scraps. Run beside regular trash cans for 3-5 scraps or dumpsters for 7-10 scraps. Direct collisions with obstacles take a heart; you get three hearts. The game and its in-game tune speed up with distance (maximum 4x). Five raccoon skins and five alleys unlock with scraps earned on runs.

AUDIO
Click "ENABLE TITLE MUSIC" on the title screen to hear the new original 8-bit menu song. Browsers require a user gesture before sound playback. Gameplay uses a separate tune that accelerates with running speed. Settings can independently disable music or sound effects.

SAVE DATA
Progress is stored locally in each browser using localStorage. Saves do not synchronize between devices or domains. The game attempts to import progress from earlier browser versions when available on the same origin.
